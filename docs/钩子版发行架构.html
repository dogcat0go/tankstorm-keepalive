钩子版 SWF 发行架构

用户电脑不编译、不装 Java、不装 ffdec。游戏点名哪一份 RedWar_*.swf，本机代理就向清单服务器要同名的钩子版，再交给本机的 Flash 窗口。

三个角色 一次启动 清单 本机代理 发布 缓存 停下来的时候 用户目录 和协议客户端的边界

三个角色

作者机器

打钩子、核对、上传

  • 从官方 CDN 下载被点名的那一版 SWF
  • 只往当版 Transport 里插入钩子
  • 锚点对得上才发布
清单服务器

按文件名提供钩子版

  • 一份清单：文件名、哈希、钩子修订号
  • 对应的钩子版 SWF 文件
  • 同时留着最近几版，供不同入口使用
用户目录

解压即用

  • 拉清单、下 SWF、起本机代理和游戏窗口
  • 证书打在目录里，不再找 OpenSSL
  • Flash 仍在本机跑

一次启动

游戏外框里的 FlashVars.version 不是 SWF 文件名。以页面实际请求的 RedWar_<版本>.swf 为准。

  1. 登录，拿到游戏外框地址。从外框或随后的 CDN 请求里读出 SWF 文件名。
  2. 向清单服务器要清单。用文件名查找。本地已有同一文件名、且哈希和修订号都一致，就用缓存。
  3. 不一致就下载这一份钩子版，校验哈希后再写入缓存。
  4. 清单里没有这个文件名，启动停在这里。窗口不要打开。
  5. 打开本机代理，只接 redwar-cdn.sincetimes.com。游戏来要这个 SWF 时，返回钩子版；图片和其他资源仍向官方 CDN 转发。
  6. 启动 flash_host。它用自带证书的 SPKI 打开游戏页。钩子通过页面里的 __pkt 把明文交回本机。

清单

服务器不提供一个叫「最新」的地址。游戏点哪个文件名，清单里就用哪个文件名当键。同一文件名后来重打了钩子，靠哈希和修订号让客户端换掉旧文件。

{
  "RedWar_2026092201.swf": {
    "sha256": "<钩子版文件的哈希>",
    "hook": 3,
    "size": 8423111
  },
  "RedWar_2026092402.swf": {
    "sha256": "<钩子版文件的哈希>",
    "hook": 1,
    "size": 8450020
  }
}
字段作用
文件名必须和游戏请求的文件名一致
sha256客户端用来确认下载完整，也用来判断要不要更新缓存
hook同一官方版本上的钩子修订。锚点没变、只修了上报时把它加一
size下载前提示体积。大于 1MB 只是文件不像主体 SWF 时的粗检，不能当作「已经可用」

本机代理

Flash 仍会向官方 CDN 要资源。代理只拦这一个主机，而且只替换被点名的那一个主体 SWF。

明文从钩子进页面的 __pkt，再由 flash_host 送到本机的记录端口。这条上报不经过清单服务器。

发布

可以上传的时候

  • 官方出现新的 RedWar_*.swf 文件名
  • 从这一份里定位 Transport，插入收发处的钩子
  • 锚点都在，钩子版能被 Flash 加载
  • 写入清单，修订号按这次发布填写

先留在作者机器上

  • 类还在，但收发锚点对不上
  • 编译或字节码补丁失败
  • 加载后钩子没有把明文交出来

厂商同时挂着两三个文件名时，清单里保留这些还在被外框引用的版本。旧到已经没有入口的文件，从清单拿掉即可。

缓存

用户目录按「文件名 + 哈希 + 修订号」保存钩子版。三次都和清单一致才直接开窗口。文件名相同但修订号变了，删掉旧文件再下新的。体积够大不能单独作为可用条件。

停下来的时候

清单没有游戏正在要的文件名，或者下载哈希对不上：不要把官方原版送进 Flash。窗口能开，钩子却是空的，后面的记录会看起来像「今天没有包」。

这时告诉用户这一版还没就绪，等清单里出现同名钩子版再启动。

用户目录里有什么

放进解压目录原因
主程序登录、读清单、下 SWF、起代理
flash_host 和 Qt 运行库本机 Flash 窗口。这是目录体积的大头
pepflashplayer.dll放在 flash_host 旁边。Flash 在用户机器上执行
代理证书、私钥、SPKI窗口只信任这一张证书，启动时不必再调用 OpenSSL
SWF 缓存和清单副本运行后生成，不必打进第一次下发的压缩包
Java、ffdec、一份冻结的 Transport 源码，都留在作者机器上，不进用户目录。

和协议客户端的边界

保活、每日任务、国战走已经还原好的协议，运行时不加载 SWF，也不访问这份清单。厂商改了 opcode 或加密时，作者重出协议表再发一版程序。钩子版 SWF 只负责让游戏窗口把明文交出来。

清单服务器上放的是打过钩子的游戏主体。它按文件名分发，用户机器不再现下官方包再改。

对应实现入口是本机 CDN 代理、flash_host，以及按 RedWar_*.swf 文件名替换主体。
